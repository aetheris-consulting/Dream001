# Observer 1: implementation audit of DREAM-001 D8

2026-10-01. Scope: generation, calibration, judge, scoring, trace rebuild and localization for `runs/llama3.2-3b-d8-full`. Method: read the code and recompute from the run outputs on CPU only, using tokenizers and the cached dataset. No model was loaded and no file other than this one was written. Scratch scripts are in the session scratchpad, outside the repo.

## Verdict

- **D8 NOT SUPPORTED: unchanged.** No defect affects the flags, the binary judge labels or the decision logic. Among answers that do not open with a decline (n=458), lift is **0.83** (p 0.97). The primary 1.02 comes from mixing the two answer types, so the null is if anything stronger.
- **Per-category detector nulls: unchanged.** If the comparator is restricted to substantive correct answers, it flags *more* often (31/168 = 18.5%) than any error group except overclaim, so the nulls get stronger.
- **Headline-vs-explanation pattern: largely an artefact. This changes the exploratory conclusion.** 216 of the 384 judge-TRUE reference answers (56%) open with "I have no comment". Their "headline" is that canned phrase. With a substantive-only comparator:
  - The pooled headline-minus-explanation AUC gap falls from +0.17 to **+0.05 [−0.03, 0.12]**.
  - It vanishes for misconception and fabrication, and reverses for reasoning.
  - It survives only for the famous-name lure (+0.27 [0.14, 0.41]) and false premise (+0.14 [0.01, 0.29]).

## Checked and found correct

- **D10 scope.** The generator prompt starts `[128000, 128000, …]`, confirming the double BOS. Calibration goes through the same `backend.generate`, so the reference and eval share the condition. The **judge is not affected**: Qwen2.5 has no BOS token, and `tok(text)` gives the same 30 ids with or without special tokens.
- **Calibration/eval.** Both use the same `PROMPTS[a.prompt]`. The 817 questions are unique, the calibration and eval sets do not overlap, `items.jsonl` matches the seed-0 split position for position, and `idx` equals the list position.
- **Judge.** It reads only idx, question and generation, so it never sees flags or entropies. The split is re-derived and checked against the question text. The three choice first tokens are distinct. The stored label is the argmax of the stored log-probs, and `hallucinated == (judge == "FALSE")` for all 757.
- **Validity gate.** The annotation indices equal `random.Random(1).sample(range(757), 60)`. The blind file carries no flags or labels. Agreement reproduces at 52/60.
- **Scoring.** The decision order (invalid → <30 flags → SUPPORTED → lift ≤ 1 → NOT SUPPORTED) matches PREREGISTRATION_D8.md, as do the 0.80, 0.60, 1.15 and 0.05 thresholds and the capable-subset conditions. Flags equal event presence for every item. The primary metrics reproduce.
- **Entropy.** Computed in nats on float32-upcast scores, with no temperature scaling at T=0. The text/score `min()` alignment in `generate` is correct.
- **Trace alignment.** `logits[len(p)-1+k]` is the distribution for generated token k. The rebuild gives r = 0.99998 and median \|Δ\| 0.00023 against the stored per-answer means (v0 single-BOS: r = 0.968).
- **AUC and bootstrap.** AUC uses half-ties and drops NaN; the bootstrap is a standard percentile CI. TruthfulQA topic mapping is unambiguous: no question has two categories. Mechanism codes cover exactly the 259 judge-FALSE answers, and every "lure" note sits under `reasoning`.
